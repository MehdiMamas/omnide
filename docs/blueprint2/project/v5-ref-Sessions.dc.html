Sessions, resume and fork

How a chat is continued, branched and named.

ActionCommandResult
Fork/branch [name], or claude --continue/--resume --fork-sessionCopies the conversation so far into a new session (new ID, own picker row); original intact; an unnamed branch takes the first prompt as its name
Resume by nameclaude --resume <name>Resumes directly if exactly one session matches, else opens the picker pre-filled
Resume in a session/resume <name>Errors if the name is not unique
Default namee.g. my-app-3fNot a resume handle
Clear/clearStarts a new empty chat; the old one is saved and reopened with /resume

Source: https://code.claude.com/docs/en/sessions
