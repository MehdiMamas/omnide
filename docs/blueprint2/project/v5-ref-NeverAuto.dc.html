Never auto-approved

What still asks, even in a permissive mode.

Always asksWhy
Tools matched by an explicit ask ruleThe user wrote the rule
Tools that need user interaction (AskUserQuestion, ExitPlanMode)The answer is the user's. In the Agent Host these two are exempt from the SDK's permissionMode auto-approval, so they always reach the approval prompt, even under bypassPermissions. ExitPlanMode shows Approve or Deny; Approve switches the chat to acceptEdits
Recognised critical-path rm and rmdir removalsDeletion cannot be undone
Reads and writes outside the working directoriesOnly when blockReads/WritesOutsideWorkingDirectories are on
Rules by mode
Deny rules block in every mode. Allow rules have no effect in bypassPermissions.
