How it was captured
Network capture of a first run of the OmnIDE build (macOS arm64, Code OSS 1.148.0, an earlier build, before the series was renumbered to 0001 to 0008 and the product settings moved to product.overrides.json), recorded in the evidence section of PR #17 as an earlier run. The raw capture file is not in the repo; the screenshots from the later fresh user-data-dir run are in docs/evidence (m1-menubar.png, m1-window.png, m1-dock.png), shown on Milestone 1 evidence.
Not verified
Windows and Linux first runs have not been captured; those builds run only in PR #17's CI. Sentry (opt-in, off until the user agrees) is not part of this capture.
