Turn on Run Everything

As a developer in a sandbox, I want Run Everything with Claude Code's own warning, so that I accept the risk knowingly; an admin may forbid it. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  1. Open the Run Mode dropdown
    Run Everything is the third row.
  2. Accept the warning
    Shown the first time; Cancel keeps the old mode.
  3. Run Everything is on
    Deny rules still apply.
  4. Admin has disabled it
    The row is greyed and cannot be picked.
