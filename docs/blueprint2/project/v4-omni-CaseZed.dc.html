Case study: Zed

Its own fast editor in Rust, and the creator of ACP, the protocol OmnIDE builds on.

Got right

  • Created ACP and opened it: any agent, any editor.
  • Claude Code via ACP since 2025-09-03, using Anthropic's own adapter.
  • Bring-your-own keys free; Pro $10.
  • Updates apply on restart, quietly.

Got wrong

  • Own engine means a small extension ecosystem; VS Code extensions do not run.
  • Years of engine work before it was usable.

What OmnIDE takes from it

  • ACP as the one agent protocol.
  • Claude Code through the official claude-agent-acp, like Zed.
  • Keep VS Code's engine so Open VSX extensions work on day one.
  • Download in the background, apply on restart.
