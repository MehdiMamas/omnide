Ask the agent, review, keep and commit

As a developer, I want to ask the agent for a change, watch it work, review the diff and commit it, so that the agent does the typing and I stay in control. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  1. Composer: prompt typed
    Prompt in the composer; Agent mode, Sonnet 5.5.
  2. Agent turn: run 1: sent
    Enter sends the turn; the prompt moves into the chat as a bubble.
  3. Agent turn: run 1: thinking
    Thinking streams in a collapsed block.
  4. Agent turn: run 1: terminal card running
    A terminal card runs node in PowerShell, inline in the chat.
  5. Agent turn: run 1: terminal output 42
    The card shows the output: 42.
  6. Agent turn: run 1: file edit card
    A file edit card writes src/hello.txt (+2).
  7. Agent turn: run 1: done, Undo / Keep / Review bar
    Turn done: answer, then the Undo / Keep / Review bar above the composer.
  8. Agent turn: changed files expanded
    The changed-files strip lists each file with + / - counts.
  9. Agent review: All Changes, 1 pending
    Review opens All Changes in the editor area, 1 pending.
  10. Agent review: commit message generated
    Commit in the review: a message is generated from the diff.
  11. Agent review: commit ready, file checkboxes
    Ready to commit with a checkbox per file. The commit itself was not captured (the Claude rate limit ended the session first).
  12. Agent turn: changes kept
    Keep in the bar accepts the change without a commit; the bar goes away.
