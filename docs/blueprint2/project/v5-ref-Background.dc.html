Task and background shortcuts

Keys and commands for the to-do list and background work.

Key or commandWhat it does
Ctrl+TToggle Claude's to-do checklist (pending, in progress, complete)
/tasksShow running shells and subagents
Ctrl+BMove a running Bash command or agent to the background (press twice in tmux)
On exitBackground tasks are cleaned up when Claude Code exits
CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1Turns background tasks off, and Ctrl+B

Source: https://code.claude.com/docs/en/interactive-mode
