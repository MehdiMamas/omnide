Distribution and signing

There is no domain and no server. The app is built with Code - OSS's own gulp tasks, signed and notarised by OmnIDE, and published to GitHub.

PartHowDetail
DomainNoneDownloads come from GitHub Releases
Update feedlatest.json on GitHub PagesRead by the app on start and on a timer
macOSSigned and notarisedThrough the owner's Apple Developer Program
Windows, LinuxSame Code-OSS gulp tasks (win32, linux)Not signed by Apple
Release checkIssue #16A tagged build installs, then updates itself from the next release. The app reads latest.json at https://mehdimamas.github.io/omnide/latest.json and sends the user to https://github.com/MehdiMamas/omnide/releases
Build scriptsCode-OSS gulp tasks onlyNo VSCodium build scripts
