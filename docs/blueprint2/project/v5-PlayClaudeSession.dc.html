Claude session, start to close

As a developer, I want to sign in and run a prompt with Claude Code, so that I can work with it inside OmnIDE. Click a step to open its screen. See the session states.

  1. Signed out
    Settings > Claude shows Sign in; the choice is a Claude subscription or an API key.
  2. Signed in
    The Agent Host starts claude and createSession opens the session.
  3. Ready, pick a mode
    The composer waits for a prompt in any of the five modes.
  4. Prompt running
    Text and tool cards stream in; Stop is available.
  5. Asked to edit
    The turn pauses until you choose Allow or Deny.
  6. Edit applied
    After you allow, the file edit card shows the change.
  7. Done
    The turn ends; Undo, Keep and Review are offered.
  8. Stop the turn
    Stop dispatches ChatTurnCancelled; the turn ends as cancelled.
  9. Reopen an old chat
    Reopening replays the history of an earlier chat.
  10. Finish and close
    The Agent Host and its claude subprocesses are stopped.
