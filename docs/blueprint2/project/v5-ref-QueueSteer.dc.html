Queue and steer

What Enter, steer and stop do while a turn runs.

InputEffect
EnterQueues the message to run after the turn
Cmd+Return (steer)Injects it at the next tool call
Stop (Cmd+Shift+Backspace, Ctrl+Shift+Backspace)Aborts: state Cancelled, then Idle
Transport errorOmnIDE retries automatically; the agent holds a wake-lock while running
Claude Code analoguesEsc interrupts and keeps work done; Ctrl+Enter sends queued messages now
