Rewind limits and warnings

What a checkpoint restore can and cannot bring back.

CaseWhat happens
Files changed only by BashNot captured; the files were never edited by Claude's edit tools
Edits by most subagents, or by another session or outside toolNot captured
Symlinked and hard-linked filesSkipped, with the warning "Restored the code, but skipped N files"
About 30 days after the last saveSnapshots are swept (cleanupPeriodDays); rewind can fail with "No files were restored"
Permanent historyUse git
Cursor comparison
Cursor keeps checkpoints in User/globalStorage/anysphere.cursor-commits/checkpoints/<request-id>/. OmnIDE uses Claude Code's own checkpointing through the user's CLI (the Agent Host Claude harness), not a Cursor-style store.
