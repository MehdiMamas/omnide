Build and CI

How OmnIDE is built from the pinned upstream tag, and what CI runs on every push and pull request. There is no smoke-test step in the build workflow yet.

StepWhat it does
1scripts/prepare_vscode.sh: reads repo and tag from upstream.json; if vscode/.git is missing it runs git init, adds remote origin https://github.com/<repo>.git and sets core.autocrlf false; then fetch --depth 1 of the tag, checkout -f and clean -fdq
2scripts/patches.sh: for each patches/*.patch, in file order, git -C vscode apply --whitespace=nowarn (prints "applying <name>")
3scripts/assets.sh: copies the icons (omnide.icns to resources/darwin/code.icns, omnide.ico to win32/code.ico, omnide.png to linux/code.png, code_150x150.png and code_70x70.png to win32/), the Geist .woff2 fonts to src/vs/workbench/browser/media/fonts/, and extensions/theme-omnide/package.json plus src/omnide/theme/*.json to vscode/extensions/theme-omnide/themes/
4cd vscode; pnpm install --frozen-lockfile; pnpm run gulp "vscode-<target>-min"

scripts/build.sh runs steps 1 to 4 in that order. With no argument it picks the target from uname: darwin-arm64, darwin-x64, linux-x64 or win32-x64.
