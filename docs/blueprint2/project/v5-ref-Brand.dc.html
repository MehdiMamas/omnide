The nine starter theme colours

Each theme file in extensions/theme-omnide sets these nine keys under "colors". Both files carry the note "Generated from docs/blueprint/tokens.json; starter set, extend in build step 1"; the values are the bg and fg steps of that file. Read from src/omnide/theme/omnide-dark.json and omnide-light.json at ded1d1e.

Theme keyOmnIDE DarkOmnIDE LightRole
editor.background#14121B#F8F6FCEditor area; same value as panel.background (bg-1)
sideBar.background#1A1823#F0EDF7Side bar (bg-2)
activityBar.background#0E0C14#FFFFFFActivity bar, deepest layer (bg-0)
titleBar.activeBackground#0E0C14#FFFFFFTitle bar, same as the activity bar (bg-0)
