Design tokens (OmnIDE Dark and OmnIDE Light)

Each token is shown dark / light with its contrast against the surface it sits on (text 4.5:1, UI parts 3:1). The same values are written to the VS Code colour themes in src/omnide/theme, and to the CSS variables every screen on this canvas uses.
