Choose Allowlist, approve a command, then always run it

As a developer who chose Allowlist, I want Claude to apply edits I can undo and ask before running a command, and remember my yes, so that I am not asked twice. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  1. New chat: Agent
    A new chat starts in the Default mode (Agent unless changed), with Run Mode Auto-review.
  2. Open the mode picker
    Agent, Plan and Ask; Shift+Tab cycles the same three.
  3. Settings: Run Mode
    Auto-review, Allowlist or Run Everything, with the protections below.
  4. Open the Run Mode dropdown
    Allowlist is the first row.
  5. Choose Allowlist on purpose
    Saved in OmnIDE's own settings; new chats use it.
  6. Start a new chat to apply it
    Restart to apply: the open chat keeps Auto-review, the new chat starts in Allowlist.
  7. Claude edits a file
    In Allowlist the edit is applied and shown with Keep or Undo.
  8. Claude asks to run a command
    npm test is not on the allowlist, so the card shows: Run, Skip or Always Run.
  9. Always Run
    The narrow rule Bash(npm test) is saved in the workspace.
  10. See the rule in Settings
    The rule is listed and can be removed.
