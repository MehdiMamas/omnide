OmnIDE components

OmnIDE is a Code OSS build with one added piece: an ACP client that talks to the official Claude Code adapter on the developer's machine. Nothing goes to an OmnIDE server; updates come from GitHub Releases. Anything marked TO VERIFY is not yet confirmed against Anthropic's docs.

OmnIDE appCode OSS fork with the OmnIDE name, logo and purple accentDeveloper's machine
ACP clientOur code: sends prompts, shows streamed replies and permission asksInside the app

Claude CodeAnthropic's CLI agent; uses the developer's own Claude sign-in or API keyDeveloper's machine
UpdaterReads latest.json from GitHub Releases, verifies the checksum, then offers a restartInside the app
