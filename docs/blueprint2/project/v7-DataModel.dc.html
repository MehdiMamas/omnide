Data model: what the permissions settings hold

Four records and a managed policy. OmnIDE settings hold the first three; the workspace file holds allow rules.

Chat
id
mode: agent | plan | ask
runMode (copy of the setting at start)
restartToApply: boolean
RunModeSetting
value: auto | allowlist | bypass
defaultChatMode: agent | plan | ask (default agent)
stored in OmnIDE settings, never ~/.claude
AllowRule
rule, for example Bash(npm test)
file: workspace .claude/settings.local.json
added by: Always Run | editor
Protection
kind: file deletion | external files
on: boolean, both on by default
best effort: ask rules, or a refusal outside the workspace
ManagedPolicy
disableAutoMode
disableBypassPermissionsMode
read only, wins over everything
1 : 11 : 0..*

Run Mode, protections and the default live in OmnIDE's own settings; allow rules live in the workspace file; the managed policy is read only. There is no OmnIDE database. Field names beyond the Claude Code keys are proposals. TO VERIFY: where the per-chat mode is kept.
