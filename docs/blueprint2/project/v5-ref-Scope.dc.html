Scope: what this canvas owns

This canvas states what OmnIDE is and does. For what it depends on, it points at the source and does not copy it.

Owned here

PartWhat it is
Patchespatches/*.patch on the pinned Code OSS tag, one concern per patch; the Patch series board has them.
Scriptsscripts/ (prepare_vscode.sh, patches.sh, assets.sh, build.sh, save_patch.sh) and upstream.json, which pins the tag.
CI.github/workflows (build, lint) and Renovate on upstream.json; the Build and CI board has them.
Brandsrc/omnide/brand, theme and fonts, and the colours and logo on the Brand values board.
The omnide.agent extensionextensions/omnide-agent (planned, see Plan): the client of the Agent Host, its panel and Settings > Claude.
Every decision made in the issuesThe issues of MehdiMamas/omnide hold the reasons; the Decisions board and this canvas carry the outcome.

Depended on, by pointer only

DependencyWhere to read it
VS Code Agent Host, at the Code OSS 1.148.0 tagsrc/vs/platform/agentHost, and node/claude for the Claude agent: https://github.com/microsoft/vscode/tree/1.148.0/src/vs/platform/agentHost (the tag in upstream.json).
The Claude Code docsPermission modes, checkpointing, legal and compliance: https://code.claude.com/docs/en.
How a rebuilder uses this
Read the Agent Host internals at the 1.148.0 tag. This canvas states an upstream behaviour only where a screen shows it or a decision rests on it: for example the plan card (Ready to code?, Approve and Deny), the rewind menu actions, and the rule that bypass cannot be entered mid-session.
Out of scope on purpose
No boards on Agent Host internals (chat truncation, setting sources, protected paths, the multi-chat lifecycle). They change with each tag, so they are read at the tag, not copied here.
