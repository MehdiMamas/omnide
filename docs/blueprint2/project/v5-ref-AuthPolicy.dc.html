Anthropic auth policy

What Anthropic's own page lets a third-party tool do with Claude Code and consumer plans, and how OmnIDE stays inside it: it runs the user's own installed claude, with no OmnIDE claude.ai login and no token passing.

OmnIDEWhat the page says (own words)
May: start the user's own installed claudeClaude Code must run as Anthropic publishes it, unmodified, with every sign-in method it ships with left working. OmnIDE starts that binary through the Agent Host and changes nothing in it.
May: let the user sign in to claudeAn end user signing in to the unmodified Claude Code binary with their own subscription is expressly allowed, also when a platform hosts it. The sign-in finishes in Anthropic's own flow (claude /login).
May: use an API key the user sets up themselvesCustomers may configure their own API key for their own users, if the usage is billed to the key owner and is not resold.
May not: add a Claude.ai login to OmnIDEThird-party apps may not offer Claude.ai login. OmnIDE has no login screen of its own for Claude.
May not: collect, store or pass on credentialsNo collecting, storing or intermediating Claude.ai credentials or session tokens, and no sending requests through a user's Free, Pro, Max or Ultra plan credentials. OmnIDE never reads or forwards a token.
May not: pay for or resell usageUsage must not be paid for, resold or intermediated on end users' behalf; each user authenticates with their own key, plan or cloud provider.
May not: use the names as its ownOmnIDE may say in plain text that it runs Claude Code. The Claude Code or Anthropic names and logos may not be part of the product name or logo, or suggest Anthropic built or endorses it.
The one sentence quoted
"Anthropic does not permit third-party developers to offer Claude.ai login into their own applications, or to route requests through Free, Pro, Max, or Ultra plan credentials on behalf of their users."
Not verified
This is a plain reading of the page, not legal advice. The page sets its conditions for products that preinstall or run Claude Code, which OmnIDE does not do (it uses the user's own install). Whether the Commercial Terms apply to OmnIDE itself is a legal question that is still open.
