Why not VSCodium

OmnIDE forks microsoft/vscode (Code-OSS) directly. VSCodium was rejected because it trails upstream.

Decision
Fork microsoft/vscode at a release tag, rebase per upstream release, build with Code-OSS gulp tasks. Not a full fork like Void, not a new engine like Zed.
