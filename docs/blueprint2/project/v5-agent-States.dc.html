Agent session: states and what moves it

One session per chat tab. The panel shows the state in its own words: the composer is disabled while Not installed or Signed out, Stop replaces Send while Running or Waiting for approval, and every Error offers Retry and Copy diagnostics. Closing the window stops the Agent Host session (issue #5).

Not installedNo Claude Code found. Install button.
Signed outHarness offers auth methods
StartingStart a harness session through the Agent Host
IdleReady for a prompt
RunningStreaming message chunks and tool calls
Waiting for approvalsession/request_permission open
Cancellingsession/cancel sent, wait for stopReason
Loading historysession/load replays updates
ErrorAgent Host or harness crashed, auth failed, or rate limit
ClosedWindow closed, Agent Host session stopped

Legend: red: failure or missing · dashed: return path
