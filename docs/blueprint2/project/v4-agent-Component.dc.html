Agent: how the pieces connect

The Agent panel is not code inside the editor core. It is the built-in extension omnide.agent, an ACP client. It starts the pinned adapter as a child process and speaks JSON-RPC over its stdin and stdout. The adapter drives Claude Code through the official SDK. Nothing talks to Anthropic except Claude Code itself.

Why an adapter and not the CLI
ACP gives one protocol for any agent, so v0.2 adds Gemini CLI or Codex with a registry entry and no UI change. The adapter is maintained by the ACP project, so protocol updates keep arriving.
Why the extension is built in
It ships inside the app, signed with it, and Open VSX is not needed to get the agent. It uses the same extension API as any extension, so a fork never patches the core for it.
Auth
Sign-in is Claude Code's own: the adapter offers terminal auth methods (claude-ai-login, claude-login, console-login). An Anthropic API key is stored in VS Code SecretStorage. OmnIDE has no account.
