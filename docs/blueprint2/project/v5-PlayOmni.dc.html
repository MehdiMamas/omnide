Every Claude Code feature

As a developer using Claude Code in OmnIDE, I want every Claude Code feature in the editor, so that I never need to leave for the terminal. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  1. Agent turn
    Claude Code answers in the chat pane.
  2. Model picker
    Pick Opus 5.5, Sonnet 5.5, Haiku 5.5 or Fable 5.2, the effort (Low, Medium, High, Extra High, Max), Fast mode and 1M context.
  3. Context meter
    The ring in the composer shows how full the context is; Compact now starts /compact.
  4. Compacting
    /compact is running.
  5. Compacted
    The summary is kept; Rewind is one click away.
  6. Plan approval
    Ready to code? Approve or Deny.
  7. Subagent transcript
    A Task card expanded to show the subagent's own steps.
  8. Todos
    Claude's todo list for the turn.
  9. Background tasks
    Dev servers and subagents still running; each can be stopped.
  10. Rewind menu
    Click a message: rewind, fork or copy.
  11. Rewind confirm
    Restore code and conversation, either one alone, summarize, or never mind.
  12. Fork conversation
    Start a new session from this message.
  13. Sessions
    Resume any earlier session from this project.
  14. About OmnIDE
    Version, licence and source; free and open source.
  15. Rate limit reached
    Claude's own limit message; no OmnIDE plan is involved.
