OmnIDE v5

OmnIDE is an open-source IDE on Code OSS where Claude Code is the agent, spoken to over the Agent Client Protocol. This page keeps the familiar layout and flows and adds OmnIDE's own mark, purple design tokens and Geist type, Claude models and wording, Settings > Claude, and the Agent design. Nothing is locked or paid. Other agents appear only as Roadmap v0.2 entries in the agent picker. Status: in progress, waiting for your yes. Plan: omnide#10. Cloud agents, voice, the browser tool, tab completion, debug mode, indexing and review providers are not in OmnIDE (see Not in OmnIDE); OmnIDE has no account of its own.

Play: start at the composer and click real buttons, or walk a scenario below. How to read: boxes are frames; blue text opens a frame; red marks a failure; screens hold only the app, explanations sit on the diagram frames. Older versions: v1 to v3 archive (separate artifact, the old one hit the 511-file limit).
