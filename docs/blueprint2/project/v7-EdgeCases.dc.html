Edge cases, with evidence

One row per edge case. Evidence is the screen that shows it and its text. The wording is the proposal; the Claude Code behaviour is from its docs, fetched 2026-11-26, not yet run.

#What happensEvidenceWay out
1Auto is unavailable (older Claude Code, unsupported model or provider)v7-edge-auto-unavailable
Chat shows: "Auto-review isn't available here, so Allowlist is on." Settings shows the same reason under Run Mode.		Falls back to Allowlist (acceptEdits and allow rules); nothing runs unasked. Pick a supported model to switch back.
2Auto skips an actionv7-edge-auto-blocked
Notice: "Auto-review skipped 1 action", with a Recently blocked list. Each entry has Always Run. No Run once: the SDK cannot re-run a refused call.		No card interrupts the user. Claude is told and carries on.
3Auto pauses (3 blocks in a row or 20 in total)v7-edge-auto-paused
Card: "Auto-review paused" with the blocked command and Skip, Always Run.		Answering resumes Auto-review for the chat.
4The classifier returns an errorv7-edge-classifier-error
Card: "Auto-review could not check this action". Nothing ran.		Claude Code asks the user instead: Run, Skip or Always Run.
5The server rejects auto mid-sessionv7-edge-auto-rejected
Notice: "Auto-review turned off for this chat", with the reason.		OmnIDE calls setPermissionMode("acceptEdits") so the chat behaves like Allowlist (TO VERIFY); a new chat tries Auto-review again.
6Claude Code older than 2.1.314v7-set-external-old
External-File Protection is shown disabled with "Needs Claude Code 2.1.314+".		Update Claude Code; writes outside the workspace are not blocked until then.
7Admin disabled Auto-reviewv7-edge-auto-admin
The dropdown row is greyed with "Disabled by your administrator". Allowlist is used.		Ask the admin; permissions.disableAutoMode is set in managed settings.
8Run Mode changed while chats are openv7-edge-runmode-changed
Open chats keep the mode they started with and show a "Restart to apply" chip. New chats use the new mode; the Default mode (Agent, Plan or Ask) for new chats is set in Settings.		Restart the chat to apply, or leave it as is.
9First time Run Everything is chosenv7-edge-bypass-dialog
OmnIDE's own dialog: "Run Everything skips every approval", with Cancel and "I accept the risk". The acceptance is stored in OmnIDE settings.		Cancel keeps the old Run Mode.
10Admin disabled Run Everythingv7-edge-bypass-disabled
The dropdown row is greyed with "Disabled by your administrator" and cannot be picked.		Ask the admin; permissions.disableBypassPermissionsMode is set in managed settings.
11Claude tries to edit in Ask modev7-edge-ask-refused
Card: "Edit refused. Ask mode has no edit access." The file is untouched.		Switch to Agent from the card, or keep asking. Commands in Ask still go through the card.
12Claude edits a file in Allowlistv7-edit-keep-undo
Edit is applied and shown with Keep and Undo.		Undo restores the file. mkdir, touch, mv, cp and sed in the working folder also run without a card; rm, rmdir, git rm and other commands not on the allowlist ask.
13Approval card skippedv7-approval-skipped
Card reads "Skipped"; Claude is told and can try another way.		Ask again, or switch Run Mode.
