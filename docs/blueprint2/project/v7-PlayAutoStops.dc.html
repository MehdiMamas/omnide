Auto-review skips, pauses and fails

As a developer on Auto-review, I want blocked actions to be skipped quietly and a card only when it truly pauses, so that I am not interrupted needlessly. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  2. Auto-review pauses
    After 3 blocks in a row or 20 in total the card shows.
  3. Always Run from the card
    Saves Bash(npm test) in the workspace.
  4. The classifier fails
    Claude Code asks instead; nothing ran.
