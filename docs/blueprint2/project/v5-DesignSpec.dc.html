OmnIDE design spec

OmnIDE keeps the VS Code layout and flows, so every habit carries over. Only the brand layer changes: mark, name, colour, type and the badges that say what is not in v0.1. Tokens and contrast are on the Design tokens frame.

Direction
Calm and technical: purple-tinted dark neutrals, one purple accent, generous contrast. Three words: focused, quiet, precise. The accent is used for the one thing to do next (primary button, focus ring, active indicator), never for decoration.
Why purple
It is the owner's default accent, it is not the colour of Anthropic or Microsoft, and it reaches 7.1:1 with white text on the button fill, so the brand is safe on contrast.
Why Geist
A neutral UI sans and a matching mono, both under the SIL Open Font License, bundled as woff2 so there is no network request and nothing to license. Codicons stay for all icons.
