Agent design · agent provider interface · v5 · 2026-11-26 · updated 2026-11-26

Adding an agent in v0.2 is enabling another Agent Host harness, not a UI change

The Agent panel talks only to the Agent Host's AgentProvider. Everything it shows (mode list, model list, Roadmap pills, the agent picker) comes from the provider's capabilities and its roadmap flag. In v0.1 only Claude Code has roadmap false; the others are listed with the pill Roadmap v0.2, no padlock.
