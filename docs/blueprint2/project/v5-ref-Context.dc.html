Context, compact and clear

Three commands that manage the window.

CommandEffect
/contextShows what fills the window
/compact [instructions]Replaces history with a summary. After it, up to five most recently touched files are re-read; files over 5,000 tokens come back as a path reference ("Referenced file")
/clearStarts a new empty conversation; the old one is saved
/autocompactSets the auto-compact window

Source: https://code.claude.com/docs/en/commands; https://code.claude.com/docs/en/context-window
