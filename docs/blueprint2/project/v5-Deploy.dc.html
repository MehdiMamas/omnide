How OmnIDE ships

OmnIDE has no server of its own. Builds, downloads and the update file all live on GitHub, so hosting costs nothing and there is no domain to buy for now.

Builds · GitHub Actions builds the patched VS Code base (scripts, a patches folder and an upstream.json, the same model VSCodium uses) for Windows, macOS and Linux.
Downloads · GitHub Releases. No domain: the owner will not buy one for now (Q2).
Updates · Planned, not in the merged build (product.overrides.json sets downloadUrl but no updateUrl): product.json will point updateUrl at a static latest.json served from GitHub Pages (https://mehdimamas.github.io/omnide/latest.json); the app fetches latest.json, downloads the release asset, checks its sha256 and offers "Restart to update". See the update flow.
Signing · macOS builds are signed and notarized (Apple Developer Program, $99/yr, which the owner has; issue #10, Q3: "sign macOS builds ($99/yr Apple Developer Program)", answered yes). Windows signing goes through SignPath Foundation if the application is accepted (Q4); until then Windows builds are unsigned and say so in the release notes. Linux updates through its package manager.
This canvas · one private claude.ai artifact, published in batches; the files live in the repo at docs/blueprint/project.
