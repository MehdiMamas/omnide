Adding an agent in v0.2 is a registry entry, not a UI change

The Agent panel talks only to AgentAdapter. Everything it shows (mode list, model list, Roadmap pills, the agent picker) comes from the adapter's capabilities and its roadmap flag. In v0.1 only Claude Code has roadmap false; the others are listed with the pill Roadmap v0.2, no padlock.
