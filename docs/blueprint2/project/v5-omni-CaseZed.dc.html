Case study: Zed

Its own fast editor in Rust, and the creator of its own open agent protocol.

Got right

  • Opened its agent protocol: any agent, any editor.
  • Claude Code through its agent protocol since 2025-09-03, using Anthropic's own adapter.
  • Bring-your-own keys free; Pro $10.
  • Updates apply on restart, quietly.

Got wrong

  • Own engine means a small extension ecosystem; VS Code extensions do not run.
  • Years of engine work before it was usable.

What OmnIDE takes from it

  • One agent protocol (OmnIDE uses VS Code's Agent Host Protocol).
  • Claude Code as the first agent, like Zed.
  • Keep VS Code's engine so Open VSX extensions work on day one.
  • Download in the background, apply on restart.
