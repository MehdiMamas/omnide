Agent turn states

Every state an agent turn passes through in the reference IDE, each with the screen that shows it.

  • Idle: composer typed prompt
  • Starting: agent turn starting
  • Streaming: agent turn streaming
  • Running tools: agent turn tools
  • Done: changes to review: changed files expanded
  • Kept: agent changes accepted
  • Restored to checkpoint: checkpoint restore
  • Stopped: stop generation
