~/.claude.jsonWritten by Claude Code itself: account details, MCP server configuration, per-project state such as trust decisions, and the global config keys that /config writes
Credential order, first match wins1 cloud provider variables (CLAUDE_CODE_USE_BEDROCK, _VERTEX, _FOUNDRY); 2 ANTHROPIC_AUTH_TOKEN; 3 ANTHROPIC_API_KEY; 4 apiKeyHelper output; 5 CLAUDE_CODE_OAUTH_TOKEN; 6 Anthropic profile or federation credentials; 7 subscription OAuth from /login
ANTHROPIC_API_KEYInteractive: asks once whether to use the key and remembers the answer. Non-interactive -p: always used when present. To fall back to the subscription, unset ANTHROPIC_API_KEY; /status shows which method is active

Session folder name: the working directory path with non-alphanumerics replaced by -, cut to 200 characters plus a hash if longer. One JSON object per line, an internal format. Kept 30 days by default (cleanupPeriodDays). Settings files are strict JSON: comments or trailing commas cause a Settings Error at the next start.
