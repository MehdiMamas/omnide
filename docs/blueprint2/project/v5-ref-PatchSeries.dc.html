Patch series

The seven patches OmnIDE applies to the fetched Code OSS tree, in the order they are applied.

#PatchWhat it changes in vscode/
0001brand-product-nameproduct.json names: applicationName omnide, dataFolderName .omnide, sharedDataFolderName .omnide-shared, server and tunnel names omnide-server and omnide-tunnel, the win32 names, licence URLs, urlProtocol and the update URL
0002telemetry-removed (adapted from VSCodium MIT, 00-telemetry-disable)Removes product.json keys agentsTelemetryAppName, webviewContentExternalBaseUrlTemplate and voiceWsUrl. Flips seven defaults to off: telemetry.telemetryLevel (ON to OFF), telemetry.enableTelemetry, telemetry.editStats.enabled, telemetry.enableCrashReporter, workbench.enableExperiments, workbench.settings.enableNaturalLanguageSearch and the workbench natural-language command search (enableNaturalLanguageSearch), each true to false
0003marketplace-open-vsxextensionsGallery serviceUrl https://open-vsx.org/vscode/gallery, itemUrl https://open-vsx.org/vscode/item, latestUrlTemplate .../gallery/{publisher}/{name}/latest and a controlUrl (EclipseFdn publish-extensions extension-control JSON); linkProtectionTrustedDomains open-vsx.org; VSCODE_GALLERY_* env overrides in product.ts; extensions.verifySignature default true to false (extensions.contribution.ts and the extensionManagementService fallback) because Open VSX has no signatures
0004copilot-chat-disabledchat.disableAIFeatures default false to true in chat.shared.contribution.ts, which hides and disables the built-in Copilot chat and inline suggestions
0005brand-fontsAdds .woff2 to the bundle asset loaders (build/next/bundle.ts); @font-face for Geist and Geist Mono (variable woff2, weight 100 900) in the workbench style.css; the workbench font-family becomes "Geist", system-ui, sans-serif on macOS, Windows and Linux
0006brand-default-themeproduct.json configurationDefaults workbench.colorTheme: "OmnIDE Dark"
0007brand-cli-namemacOS only: build/gulpfile.vscode.ts renames bin/code to bin/<applicationName> when packaging for darwin; nativeHostMainService.ts getShellCommandLink and the built macOS CLI path use bin/<applicationName>
Rules
Patches live in patches/ and are applied in file-name order by scripts/patches.sh with git apply. vscode/ is fetched at the pinned tag and never hand-edited; every change to it is a patch, one concern per patch. Order matters: a patch that no longer applies after an upstream bump fails the build workflow.
