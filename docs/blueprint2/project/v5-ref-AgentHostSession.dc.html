Agent Host session, turn and cancel

The commands and actions of one chat, with the error that sends the user to sign in.

StepMessageWhat happens
CreatecreateSession (working directory, config such as permissionMode)ClaudeAgent binds a provisional session; it materialises on the first send
No credentialsError AHP_AUTH_REQUIRED (-32007, AuthRequiredErrorData)Client answers the authenticate command, then retries
Turn ends wellChatTurnCompleteTurnState complete; queue drained after the SDK result
User cancelsChatTurnCancelledTurnState cancelled
Turn failsChatErrorTurnState error: SDK result with an error, or the stream ended without a result
Cancel pathClient dispatches ChatTurnCancelled; AgentSideEffects calls agent.chats.abortPipeline interrupts the query, aborts the controller, fails pending work; pending permission asks are denied, pending inputs cancelled; queued messages are not drained
Restore Checkpoint to turn NtruncateChat(turnId = N)Keeps turns 0..N inclusive, on the same session id. Per-turn rows past N (file edits, checkpoint refs) are pruned and the next send resumes the SDK at turn N's assistant message
Turn not in the transcripttruncateChat with an unknown turn idThrows: Cannot truncate session <sdkSessionId>: turn <turnId> not found in transcript
Start overtruncateChat(turnId undefined)Deletes the transcript through the SDK (deleteSession) and recreates a fresh session with the same chat and the same session id; all per-turn rows are removed
Chat not started yettruncateChat on a provisional chatNothing to truncate: it logs and returns
Fork, turn not foundcreateChat with a fork of a source chatLogs a warning (turn not found in source; creating fresh chat) and creates a fresh chat instead of failing. A source with no backing session does the same
