Shift+Tab mode cycle

Each press moves to the next mode: Manual, Accept edits, Plan, then Bypass permissions if it is available, then Auto if it is available, then back to Manual. From Auto the first press goes to Manual. Windows fallback: Alt+M. Order read from the installed Claude Code 2.1.332 (its mode-cycle function) and stated in the permission-modes docs.

Mode names: Claude Code and the Agent Host

OmnIDE's mode picker is the Agent Host "Approvals" setting, so it shows the Agent Host labels. The CLI names and the status texts above are the CLI's own and appear only when the CLI itself is used. The mockup screens on this canvas still draw the CLI names; which set the final picker shows is not changed on this page.
