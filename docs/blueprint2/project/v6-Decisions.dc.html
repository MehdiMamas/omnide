Decisions

What was chosen, what was turned down and why. Newest first. The five-modes wording is from issue #19; the docs list six values.

Two settings, Mode and Run Mode

Claude Code has one list of modes that mixes what Claude does with how much it asks. Cursor splits them, and the owner chose that on 2026-11-26.

  • Chosen: The chat picker holds Agent, Plan and Ask. Settings holds Run Mode: Auto-review, Allowlist, Run Everything. Together they map onto Claude Code modes.
  • Rejected: Show Claude Code's modes in one picker (default, acceptEdits, plan, auto, bypassPermissions): Shift+Tab would reach bypassPermissions, and users cannot tell "what Claude does" from "how much it asks"
  • Rejected: Also offer dontAsk: it is for non-interactive CI runs and would make a chat silently refuse anything not allowed

New chats start in Agent with Auto-review

A default has to be safe and useful without setup.

  • Chosen: Agent with Auto-review, configurable in Settings. Where Auto is unavailable the chat starts in Allowlist with a notice.
  • Rejected: Start in Allowlist everywhere: asks far more often and teaches users to click Always Run without reading
  • Rejected: Start in Run Everything: turns approvals off before the user chose it

Ask is Plan plus a rule

Claude Code has no answer-only mode.

  • Chosen: Ask starts Claude Code in plan mode with a rule that it never proposes edits; an edit that still happens is refused.
  • Rejected: Drop Ask and keep Plan only: the issue asks for Cursor's three modes, and a pure question should not produce a plan
  • Rejected: Ask as Agent with all tools denied: Claude could not read files to answer

Keep Claude Code's bypass dialog and the admin block

Run Everything removes every approval.

  • Chosen: Show the warning Claude Code shows, once, and grey the option when managed settings disable it.
  • Rejected: Write skipDangerousModePermissionPrompt ourselves: it hides the one warning that explains the risk
  • Rejected: Hide the option when disabled: the user cannot see why a mode they expect is missing
