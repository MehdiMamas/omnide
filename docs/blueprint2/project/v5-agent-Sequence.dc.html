Agent: one prompt turn, message by message

Names are the Agent Host Protocol's (microsoft/vscode 1.148.0, src/vs/platform/agentHost): commands createSession and authenticate, session channels ahp-session:/<uuid>, chat actions ChatTurnComplete, ChatTurnCancelled and ChatError. Claude's own tools (file edits, shell) run inside the claude subprocess; the Agent Host reports them as tool calls with a ToolKind, and the panel shows them and answers permission asks. Cancel can come at any point in the turn.
