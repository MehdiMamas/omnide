Colour tokens

Status: current. Created 2026-11-26. Updated 2026-11-26.

Dark theme first (a light theme follows in v0.2). Contrast is checked against the "On" colour: 4.5:1 for text, 3:1 for UI.

TokenValueOnUseWhy
--bg#0F1216--inkuiEditor and canvas background. Near-black with a blue cast so long sessions are easy on the eyes; not pure black, which smears on OLED and looks harsh next to code.
--surface#171B21--inkuiPanels, cards, sidebar. One step lighter than bg so layers read without borders everywhere.
--ink#E6EAF0--bgtextBody text and code. Off-white, 14:1 on bg, softer than #FFF for hours of reading.
--muted#9AA4B2--bgtextSecondary text, line numbers, timestamps. Still above 4.5:1 so nothing important is unreadable.
--line#5C6776--bguiBorders and dividers. The lightest grey that still passes 3:1, so inputs and focus edges stay visible.
--accent#2BD4A4--bguiBrand teal: primary buttons, links, the logo, the agent that is ready. Not blue, so OmnIDE does not look like VS Code, Zed or Copilot at a glance.
--on-accent#06231B--accenttextText on teal buttons. Dark green-black keeps 9:1 on the accent.
--warn#F5B83D--bguiAmber: the agent needs you (permission prompt, sign-in, update ready). One colour means "your turn" everywhere.
--error#F0616D--bguiRed only for failures: missing binary, denied edit, failed update check. Never decoration.
--error-bg#2A1519--inkuiTinted background behind an error card, so the red stays for the border and icon.
--ok#5FD08A--bguiGreen for done and kept: written files, passed checks, diff additions.
--ok-bg#12261B--inkuiTinted background for added lines in a diff.
--dg-bg#0B0E12--dg-inkuiDiagram panel background, darker than bg so diagrams sit apart from screens.
--dg-lane#141920--dg-inkuiSwimlane band, just visible against the diagram background.
--dg-node#1C222B--dg-inkuiStep cards in diagrams.
--dg-line#6B7787--dg-nodeuiArrows and card borders in diagrams; 3:1 on the card colour.
--dg-ink#E6EAF0--dg-nodetextText inside diagrams.
--dg-muted#9AA4B2--dg-bgtextLane labels and notes in diagrams.
