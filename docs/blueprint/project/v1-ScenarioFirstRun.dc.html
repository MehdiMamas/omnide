First run with Claude Code

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a developer trying OmnIDE for the first time, I want to set up Claude Code in one click and review its first edit, so that I see the value before I configure anything.

Done when

  • Two clicks from Welcome to a ready Claude Code panel when Claude Code is installed and signed in.
  • No file changes without an Allow click.
  • Every edit opens as a diff with Keep and Revert.

Steps (click one to open its screen)

  1. Opens OmnIDE; the Welcome tab offers "Set up an agent". → Welcome · idle
    System: No agent process runs yet.
  2. Clicks "Set up an agent". → Welcome · u_open
  3. Sees agents from the ACP registry, Claude Code first. → AgentPicker · p_spawn · GET cdn.agentclientprotocol.com/registry/v1/latest/registry.json
    System: Fetches the registry feed (cached a day); only Claude Code is enabled in v0.1.
  4. Clicks "Use Claude Code". → AgentPicker · starting · RPC initialize
    System: Spawns claude-agent-acp over stdio and sends initialize with protocolVersion 1 and its capabilities (fs, terminal, auth.terminal).
  5. The panel opens: "Claude Code is ready". → ChatEmpty · d_found
    System: The adapter found claude (CLAUDE_CODE_EXECUTABLE, PATH, or its bundled copy).
  6. → ChatEmpty · a_auth · RPC session/new
    System: Already signed in, so session/new returns a sessionId for the workspace folder.
  7. Prompt box is live. → ChatEmpty · ready
  8. Types "Add a test for parseDate" and presses Enter. → ChatStreaming · u_prompt · RPC session/prompt
  9. Sees the plan and tool cards stream in. → ChatStreaming · prompting · RPC session/update
    System: Each session/update notification adds text or a tool card.
  10. → ChatStreaming · a_prompt
    System: The adapter forwards the turn to Claude Code through the Agent SDK.
  11. Card: "Read src/date.ts". → ChatStreaming · c_work · RPC fs/read_text_file
    System: Claude reads through the editor, so unsaved changes are included.
  12. Card: "Run npm test", 12 passed. → ChatStreaming · c_work · RPC terminal/create
    System: The command runs in an OmnIDE terminal the user can open.
  13. Sees "Claude wants to create a file" with Allow once / Allow edits this session / Deny. → Permission · p_perm · RPC session/request_permission
  14. → Permission · awaiting
    System: The turn waits; nothing is written.
  15. Clicks Allow once; the new file opens as a diff. → Diff · p_write · RPC fs/write_text_file
    System: OmnIDE writes the file and saves a checkpoint first.
  16. Clicks Keep. → Diff · u_review
    System: The checkpoint is dropped; Revert would restore it.
  17. Sees "Done." and the new file in the explorer. → ChatDone · ready
    System: The turn ends with stopReason end_turn.
