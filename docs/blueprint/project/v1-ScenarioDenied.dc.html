edgeAgent flow (node: denied)

Edit denied, or stopped

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a developer, I want to refuse an edit and have Claude carry on without it, so that nothing touches my files without my yes.

Done when

  • Deny writes nothing and Claude is told.
  • Stop ends the turn at once.

Steps (click one to open its screen)

  1. Sees the permission card. → Permission · p_perm · RPC session/request_permission
  2. Clicks Deny; the card shows "you said no". → Denied · e_denied
    System: OmnIDE answers the request with the reject option; no write happens.
  3. Can type the next prompt. → Denied · ready
  4. Or presses Stop while Claude works. → ChatStreaming · a_prompt · RPC session/cancel
    System: session/cancel; the turn ends with stopReason "cancelled".
