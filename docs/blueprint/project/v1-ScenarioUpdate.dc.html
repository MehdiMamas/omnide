Update available

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a developer, I want updates to download quietly and apply on restart, so that I stay a few days behind VS Code without doing anything.

Done when

  • The download is checked against sha256 before it is offered.
  • Restart reopens the same windows and chats.

Steps (click one to open its screen)

  1. Keeps working. → ChatEmpty · up_check · GET versions/stable/{os}/{arch}/{type}/latest.json
    System: On start and then on a timer, the app fetches latest.json for its platform.
  2. → ChatEmpty · up_get
    System: GitHub serves the file from the versions repo (free, cached by GitHub).
  3. → ChatEmpty · up_new
    System: Compares productVersion and commit with its own build.
  4. → ChatEmpty · up_download · GET github.com/{org}/omnide/releases/download/{version}/{file}
    System: Downloads the signed installer from GitHub Releases in the background.
  5. → Update · up_verify
    System: sha256 of the file equals sha256hash in latest.json.
  6. Sees "OmnIDE 1.149.0 is ready" with Restart to update. → Update · up_notify
  7. Clicks Restart; windows reopen on the new version. → ChatEmpty · up_apply
