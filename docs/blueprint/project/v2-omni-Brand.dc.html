OmnIDE: name, logo and purple

OmnIDE is spelled with a capital IDE so it reads Omn-I-D-E. Lowercase omnide stays for the repo, CLI command, data folder and URL scheme, so nothing technical breaks.

Logo idea
An open ring (omni, all around) with a gap on the right where a text caret sits: an editor open to any agent. One colour, works at 16 px and in monochrome. Wordmark: Omn regular, IDE bold.

Why purple

The owner's choice ("i am a purple guy"). It also differs from the blue used by VS Code, Zed and Copilot, so OmnIDE does not look like a Microsoft product.
