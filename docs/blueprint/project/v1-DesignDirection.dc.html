Visual direction

Status: current. Created 2026-11-26. Updated 2026-11-26.

Palette and type from: own: OmnIDE is a new product with no shipped theme yet; this canvas sets its first palette

Subject: an open, agent-first code editor for developers who live in it all day and want to see exactly what an agent is doing.

Three adjectives

  • Calm: near-black blue-grey surfaces, one accent, no gradients; hours of use without glare.
  • Honest: every agent action is a visible card with its state; amber means "your turn", red only means broken.
  • Open: the ring logo with a gap; plain IBM Plex type, no proprietary fonts.

One detail only this subject has

The caret in the logo's gap returns as the agent's "ready" dot in the status bar: the same teal mark means "you can type".

What it avoids

No purple AI gradients, no sparkle icons, no glass cards, no Microsoft blue (looks like VS Code and invites trademark trouble). Screens keep VS Code's layout so muscle memory transfers; only colour, brand and the agent panel are new.
