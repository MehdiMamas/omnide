OmnIDE: name, logo and where it appears

OmnIDE is spelled with a capital IDE so it reads Omn-I-D-E. Lowercase omnide stays for the repo, the command, the data folder and the URL scheme. Three marks were drawn; variant A is used everywhere.

A. Ring and code caret (›)
Chosen
A purple O ring (omni: all around) holding the code caret (›), the prompt caret of a terminal. Reads as a code prompt and as an O at 16 px.
