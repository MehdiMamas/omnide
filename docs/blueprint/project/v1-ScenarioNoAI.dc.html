No AI at all

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a developer who does not want AI, I want OmnIDE to work as a plain editor with no agent process and no AI network calls, so that I can use it anywhere.

Done when

  • No adapter process and no registry fetch while AI is off.
  • Turning AI on later needs no reinstall.

Steps (click one to open its screen)

  1. Clicks "Skip, use without AI". → Welcome · idle
  2. Sees the editor with no agent panel; status bar says "AI off". → EditorNoAI · off
    System: Setting omnide.ai.enabled = false; nothing is spawned or fetched.
  3. Can turn agents on later in Settings → Agents. → AgentsSettings · off
