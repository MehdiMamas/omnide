As a developer, I want to see what went wrong when the adapter fails, so that I can retry or sign in again. Click a step to open its screen. See the session states.

  1. Error state
    The adapter exited or the request failed; the pane shows the message and Retry.
  2. After Retry
    A new session starts and the pane is ready again.
