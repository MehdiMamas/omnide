ER diagram: what OmnIDE stores locally

Status: current. Created 2026-11-26. Updated 2026-11-26.

No server, no account. Everything lives on the user's machine; OmnIDE never stores Claude credentials (they stay in Claude Code).

command, args[], env{}

Session
id PK
agentId FK
acpSessionId
cwd, createdAt
transcript (messages)
workspaceStorage, per folder
PermissionGrant

Secrets: an Anthropic API key, if chosen, goes into VS Code SecretStorage (OS keychain), never settings.json.
