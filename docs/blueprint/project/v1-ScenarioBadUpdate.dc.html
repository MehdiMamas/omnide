Update fails its check

Status: current. Created 2026-11-26. Updated 2026-11-26.

As a developer, I want a broken or tampered download to be thrown away, so that a bad update can never replace a working editor.

Done when

  • Nothing is installed when the checksum differs.
  • The next check retries on its own.

Steps (click one to open its screen)

  1. Keeps working. → ChatEmpty · up_verify
    System: The downloaded file's sha256 differs from latest.json.
  2. Sees "Update couldn't be verified. Nothing changed." → UpdateFailed · up_badhash
    System: File deleted, error logged, retried at the next check.
  3. Clicks Dismiss and carries on. → ChatEmpty · up_check
