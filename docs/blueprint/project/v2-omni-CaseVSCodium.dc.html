Case study: VSCodium

Not a fork in spirit: scripts plus a patches folder that build Microsoft's open source into clean binaries. The model for OmnIDE's build.

Got right

  • Thin patch set on Code - OSS, daily automated builds.
  • Telemetry off, Open VSX as the marketplace.
  • Free updates: static JSON in a GitHub repo plus GitHub Releases.
  • Documents which Microsoft extensions do not work.

Got wrong

  • Open VSX security incidents hit its users (Oct 2025 token leak and GlassWorm; Jan 2026 hijacked extensions).
  • No AI features, by design.

What OmnIDE takes from it

  • Same build: scripts, patches and upstream.json in GitHub Actions.
  • Same update channel: updateUrl to a versions repo.
  • Same Open VSX, plus a warning for unverified publishers.
