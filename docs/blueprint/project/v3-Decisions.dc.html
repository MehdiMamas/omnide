Decisions

What was chosen, what was turned down and why. Newest first.

Design starts as a copy of OmnIDE As-is

The owner rejected the v1 scratch design on 2026-11-26: it was nowhere close to the OmnIDE As-is canvas.

  • Chosen: Copy the 265 OmnIDE v2 boards, keep names, positions and sizes, and change only what OmnIDE needs.
  • Rejected: Keep and tweak the v1 scratch design: the owner already said no to it
  • Rejected: Redraw the screens by hand: slow, and it drifts from the reference the owner wants to see

Purple accent

The owner's words: "i am a purple guy, make it purple instead of the lime".

  • Chosen: Purple #7C3AED for buttons, #B69CFF for links and focus on dark. It also stands apart from the blue of VS Code, Zed and Copilot.
  • Rejected: Teal (v1): the owner did not want it
  • Rejected: OmnIDE's blue: looks like every other VS Code fork

Claude Code over ACP

The first agent has to work on day one without OmnIDE building an agent.

  • Chosen: Claude Code through the official claude-agent-acp adapter, using the user's own Claude Code sign-in or an API key. Gemini CLI, Codex and Copilot CLI come in v0.2 from the open ACP registry.
  • Rejected: Build our own agent: Void did that and was archived on 2026-06-02
  • Rejected: Bundle Anthropic's SDK in the app: OmnIDE would handle the user's tokens; the adapter keeps them in Claude Code

Thin patches on Code - OSS

One maintainer has to be able to keep up with upstream.

  • Chosen: Scripts plus a patches folder, built in GitHub Actions, like VSCodium; extensions from Open VSX.
  • Rejected: A full fork like OmnIDE or Void: months behind upstream, hard to maintain
  • Rejected: A new engine like Zed: years of work and no VS Code extensions

Updates from GitHub Releases

No server to run or pay for.

  • Chosen: A static latest.json in a versions repo and the installer on GitHub Releases, sha256 checked.
  • Rejected: An own update server: costs money and needs care

No domain for now

The owner will not buy one yet.

  • Chosen: Downloads and latest.json are served from GitHub; the name stays lowercase omnide for the repo, CLI and URL scheme.
  • Rejected: Buy omnide.dev or omnide.io now: costs money; the owner said not now
