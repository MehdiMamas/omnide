Type, spacing and motion

Status: current. Created 2026-11-26. Updated 2026-11-26.

  • IBM Plex Sans for UI: open licence, clear at 13 px, wider than Inter so it does not look like every other AI tool.
  • JetBrains Mono for code and tool cards: free, ligatures optional, the most used free coding font after the defaults.
  • Sizes: 13 px UI (VS Code default), 15 px agent text, 20 px settings titles, 44 px only on Welcome.
  • Spacing on a 4 px grid; VS Code's own paddings are kept so extensions still fit.
  • Motion: none except the streaming text and a 150 ms fade on toasts; respects reduced motion.
