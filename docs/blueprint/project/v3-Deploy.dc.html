How OmnIDE ships

OmnIDE has no server of its own. Builds, downloads and the update file all live on GitHub, so hosting costs nothing and there is no domain to buy for now.

Builds · GitHub Actions builds the patched VS Code base (scripts, a patches folder and an upstream.json, the same model VSCodium uses) for Windows, macOS and Linux.
Downloads · GitHub Releases. No domain: the owner will not buy one for now (Q2).
Updates · product.json points updateUrl at a static versions repo; the app fetches latest.json, downloads the release asset, checks its sha256 and offers "Restart to update". See the update flow.
Signing · macOS builds are signed and notarized (the owner has the Apple Developer Program). Windows signing goes through SignPath Foundation if the application is accepted (Q4); until then Windows builds are unsigned and say so in the release notes. Linux updates through its package manager.
This canvas · one private claude.ai artifact, published in batches; the files live in the repo at docs/blueprint/project.
