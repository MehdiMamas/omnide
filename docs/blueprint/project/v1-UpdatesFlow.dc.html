Why static JSON on GitHubNo server to run or pay for. VSCodium has shipped this way for years: updateUrl = raw.githubusercontent.com/VSCodium/versions, files like stable/win32/x64/user/latest.json with url, version, productVersion, sha256hash, timestamp.
Never assumedThat the download is intact: the sha256 is checked, and the installer itself is code-signed (Windows via SignPath, macOS via Apple notarisation) so the OS checks it too.
