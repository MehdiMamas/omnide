Case study: Void

An open-source Cursor alternative (Apache-2.0, about 28.7k stars) that stopped: archived on 2026-06-02 as deprecated.

Got right

  • Open source and bring-your-own model.
  • Proved strong demand for an open AI editor.

Got wrong

  • A full fork with its own AI stack, kept by a tiny team.
  • Every agent feature built by hand, so it could not keep up with Claude Code, Codex and others.
  • Fell behind upstream and was archived.

What OmnIDE takes from it

  • Do not build the agent: plug in agents through ACP.
  • Reuse vscode-acp (MIT) for the panel instead of writing one.
  • Keep the patch set small enough for one maintainer.
