A command fails and the agent retries

As a developer, I want the agent to notice when its command fails and fix it itself, so that one shell quirk does not end the task. Click a step to open its screen; each screen links on through its real buttons. See the flow.

  1. Agent turn: run 2: sent
    Prompt sent.
  2. Agent turn: run 2: thinking
    Thinking.
  3. Agent turn: error
    Error: PowerShell removed the quotes around done, so Node threw ReferenceError: done is not defined.
  4. Agent turn: run 2: planning next moves
    The agent plans its next moves from the failed output.
  5. Agent turn: run 2: retry running
    Retry with other quoting runs.
  6. Agent turn: run 2: retry output
    Retry output: process.exit(3) exited 3; Node v24.18.0.
  7. Agent turn: run 2: answer
    Final answer with the exit codes.
