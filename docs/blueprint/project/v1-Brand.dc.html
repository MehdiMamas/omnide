Rebrand: Omnide → OmnIDE

Status: current. Created 2026-11-26. Updated 2026-11-26.

OmnIDE
Name
  • OmnIDE: "omni" (any agent, every language) + "IDE". The capital IDE makes it read Omn-I-D-E, not "omni-dee" or "om-nide".
  • Wordmark: "Omn" regular, "IDE" bold, IBM Plex Sans.
  • Lowercase omnide stays for the repo, CLI command, data folder and URL scheme, so nothing technical breaks.
Logo idea
  • An open ring (omni = all around) with a gap on the right where a text caret sits: an editor that is open to any agent.
  • Single colour, works at 16 px, as a filled app icon, and in monochrome.
  • Avoids blue and the VS Code ribbon so it never looks like a Microsoft product (trademark).
Colours, with reasons
  • ■ Teal #2BD4A4: ready, go, brand. Cursor is black/white, VS Code and Zed blue, so teal stands apart.
  • ■ Amber #F5B83D: "your turn": permission, sign-in, update.
  • ■ Red #F0616D: only real failures.
  • Full table with contrast: Colour tokens.
Name checks (2026-11-26)
  • No editor product called OmnIDE found; small GitHub namesakes only (OmniNodeCo/OmniIDE, nihannihu/Omni-IDE, EdizArkin/OmnIDE).
  • omnide.com and omniide.com taken; omnide.app parked; omnide.dev and omnide.io gave no answer (not proof they are free).
  • No trademark search yet: see Questions.
