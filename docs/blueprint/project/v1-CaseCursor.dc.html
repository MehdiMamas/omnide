Case study: Cursor

Status: current. Created 2026-11-26. Updated 2026-11-26.

A closed VS Code fork with its own AI. Huge success, and the clearest list of what to avoid.

Got right
  • AI-first layout people love: agent panel, Tab, inline edit.
  • Fast, visible response to backlash (refunds after the June 2025 pricing change).
  • Rules, MCP and skills in plain files.
Got wrong
  • Pricing switch in June 2025 surprised paying users (TechCrunch, 2025-07-07).
  • Long upstream lag: still built on VS Code 1.105 months after newer releases shipped (forum thread 164204).
  • Microsoft's C/C++ extension stopped working in forks (The Register, 2025-04-24).
  • Closed: users cannot pick the agent or the model provider freely.

What OmnIDE takes from it

  • Copy the layout, not the lock-in: any ACP agent, the user's own account.
  • No OmnIDE billing at all: users pay their agent directly.
  • Stay close to upstream with a thin patch set.
  • Same file formats (AGENTS.md, mcp.json, SKILL.md).
