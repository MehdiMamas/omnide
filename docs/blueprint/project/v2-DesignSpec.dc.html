What makes OmnIDE look rich

Measured from the live app, not guessed. Colours and type come from OmnIDE's own theme variables (source named on the tokens frame).

Two-tone surfaces
Chrome #141414 and pane #191919: the editor and the Agent pane float on a slightly darker frame. Borders are 8% white hairlines (rgba(245,245,245,.08)) used sparingly.
Text in tiers
One ink colour, then 74%, 40% and 20% mixes of it (color-mix in srgb) for secondary, hints and disabled. Hierarchy without new colours.
One saturated accent
Purple #7C3AED fills only primary buttons; #B69CFF marks links and focus. Everything else is greyscale, so status colours (amber M, teal U, red errors) stand out.
Soft radii
2, 4, 6, 8 and 12px (--cursor-radius-*): 4px on chips and menus, 8px on cards, 12px on the composer. Full pills on badges.
Layered elevation
Menus and quick input float with --cursor-shadow-workbench: 0 0 8px 2px black at 40% of 20%. Quiet, never a hard drop.
Dense but even rhythm
22px status bar, 35px title bar and tabs, 22px list rows, 13px base type: VS Code density kept, with the Agent pane at 15px for reading.
Icon fonts
codicon (VS Code), cursor-icons and seti file icons, all font glyphs at 16px; the canvas embeds the same fonts.
Motion
Short fades on menus and hovers; this capture ran with reduced motion on, so no animation is shown.
