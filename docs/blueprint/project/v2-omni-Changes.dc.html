Cursor screen groups and what OmnIDE v0.1 does with them

Every Cursor feature OmnIDE does not have in v0.1 keeps its screen in this canvas. This table says what happens to each group: kept, changed, new, later (with its issue) or dropped, and why.

Cursor screen groupOmnIDE v0.1Why

Composer signed out (st-01)changedShows Claude Code not found or not signed in, with a way to fix it.
