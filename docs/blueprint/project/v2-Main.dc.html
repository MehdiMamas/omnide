OmnIDE v2

OmnIDE is a Code OSS editor with Claude Code built in over ACP. This page is a copy of the Cursor As-is canvas (every screen rebuilt from the running Cursor 3.32.4) with OmnIDE changes on top: new name and logo, a purple accent, Claude Code as the one agent, and six new screens. Status: current, waiting for your yes. Plan: omnide#10. Not applicable: cloud agents, plans and billing, and Cursor sign-in are kept as reference screens and listed on Changes with the reason.

Play: start at the composer and click real buttons, or walk a scenario below. How to read: boxes are frames; blue text opens a frame; red marks a failure; screens hold only the app, explanations sit on the diagram frames. Older version: v1 · As-is (superseded) · page v1.
