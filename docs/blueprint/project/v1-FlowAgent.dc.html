Agent flow: from "Set up an agent" to a reviewed edit (UML activity diagram)

How one prompt travels: OmnIDE's agent panel is an ACP client, claude-agent-acp is the ACP agent, and it drives the unmodified Claude Code. The usual failures are a missing binary, an expired sign-in and a denied edit. Status: current. Created 2026-11-26. Updated 2026-11-26.

Why ACP and the official adapterOne protocol for every agent (52 listed in the ACP registry), and Claude Code stays Anthropic's own binary, so its sign-in and terms stay Anthropic's. OmnIDE only speaks JSON-RPC over stdio.
Never assumedThat Claude Code is installed, signed in, or allowed to write. Every write goes through request_permission and fs/write_text_file, so OmnIDE can checkpoint first.
